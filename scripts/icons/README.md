# 桌面快捷方式图标

图标沿用项目的通联节点、六边形和无线信号标志，配色来自界面主题。

| 脚本 | 对应图标 | 含义 |
| --- | --- | --- |
| `scripts/dev-start-hidden.vbs` | `scripts/icons/wrj-start.ico` | 青绿色播放标记，后台启动服务 |
| `scripts/dev-stop.cmd` | `scripts/icons/wrj-stop.ico` | 红色方块，正常停止服务 |

## 设置方法

1. 将更新包解压到 `start.cmd` 所在的部署根目录，为上述两个脚本分别创建桌面快捷方式。
2. 右键桌面快捷方式，打开“属性 → 快捷方式 → 更改图标 → 浏览”。选择部署目录中对应的 `.ico` 文件，确定并应用。
3. 可将快捷方式重命名为“通联仿真－启动”和“通联仿真－停止”。

图标放在部署目录内，设置后保留该目录和文件；移动整个部署目录后，需要更新快捷方式的目标和图标路径。不要只把脚本移动到桌面运行。

每个 `.ico` 含 16、20、24、32、40、48、64、96、128、256 像素的透明图标，供 Windows 按显示比例选择。同名 `.svg` 是可编辑矢量源；快捷方式选择 `.ico`。
