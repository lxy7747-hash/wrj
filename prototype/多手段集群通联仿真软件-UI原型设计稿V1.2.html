三 CSV vs 旧内部候选
采用：link_quality.csv、events.csv、link_switch.csv；其余仅为内部候选，不承诺输出。
五态 vs 六态
采用：UI 生命周期显示 IDLE、RUNNING、PAUSED、STOPPED、COMPLETED、ERROR 六态；SRS canonical SimulationState.status 保留其五个源枚举，STOPPED 作为不直接序列化的 UI 生命周期扩展。
两态 vs 三态链路
采用：UI 展示 UP / DEGRADED / DOWN；SRS canonical LinkStatus 与 link_quality.csv 只允许 UP / DOWN，DEGRADED 是内部展示扩展，写入前必须依据阈值映射且不得进入 canonical 字段。
loopback 消息通道 vs 无外网
采用：未来实现只绑定 127.0.0.1，不开放外部网卡；本单文件原型保持零连接。
四类业务信息节点 vs 支撑实体
采用：系统支持后方指挥节点、高空前出中继节点、地面无人集群指挥车、空中无人作业集群四类业务信息节点；通信卫星、地面固定式干扰侦测站为支撑实体。场景至少保留 1 个业务信息节点，未使用的业务类型只作能力覆盖提示；50 个业务信息节点上限仅统计业务信息节点。
报告导出权限 / 分级
采用更严格边界：operator 可导出普通 Level II 业务报告；批量对比报告固定为 Level III，仅 admin 且二次确认后返回带身份/时间水印的导出成功状态。原型不生成文件。
SRS 五接口 vs 详细设计稀疏接口
