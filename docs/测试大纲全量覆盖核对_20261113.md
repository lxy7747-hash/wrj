## B.3 结论
- **大纲真正要求、且已进脚本的环境参数**：#2 降雨强度、#8 云雾含水量、#10 大气模型(ITU)、#14 海面多径开关、#15 海况等级（并整体满足 GNZB-05 可配、GNZB-06 越界校验、GNZB-08 写入脚本）。
- **大纲没点名、属实现细节/超额**：#3、#4、#6、#7、#11、#16–#22。
- **大纲复合损耗模型里没有的损耗分量（需重点说明）**：#12 极化失配、#13 指向误差（当前默认 0，保持 0 不影响口径；若改非 0 会偏离 GNZB-11/XNZB-07 的损耗基准）。
- **模板默认值 vs 程序默认值有 3 处不一致，验收前必须对齐**：
  1. `simplified_attenuation_db_per_km`：模板 0.02 / 程序 0；
  2. `sea_state.enabled`（海面多径开关）：模板 true / 场景默认 false；
  3. `sea_state.sea_polygon`：模板含 4 顶点示例 / 程序默认空。
- **温度、湿度、雨衰(dB/km)** 已作为下线字段（`RETIRED_ENVIRONMENT_KEYS`），脚本中不出现，符合大纲未要求。
