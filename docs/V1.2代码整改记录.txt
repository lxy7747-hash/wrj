一、本轮代码结果

1. 场景文件完整往返（GNZB-28）
新增 wrj.scenario.snapshot v1 外壳，保存 config 与 uiExtensions，不保存服务器修订号、锁状态等运行属性。
导入、导出和覆盖提示均支持新版；旧版纯 ScenarioConfig JSON 继续可导入。
保留传感器原生 ESM 设置等扩展。未知版本、异常外壳或无效扩展在提交前拒绝，不覆盖原场景。
真实运行配置锁也读取新版场景编号。导出边界使用 toRaw，避免响应式对象导致 structuredClone 失败。
权威 TypeScript 合同副本、OpenAPI 导入请求及参数 Schema、合同审计快照同步更新，避免页面和接口允许的配置不一致。
主要文件：src/features/scenarios/scenario-snapshot.ts；ScenarioWorkspace.vue；server/scenarios/projection.ts；server/app.ts。

2. 运动字段（GNZB-08）
新增平台初始航向、航点航向及加速度的输入、保存和字段校验。
平台初始航向映射到已有 heading 原生指令。
航点航向、加速度保留到生成清单；尚未找到已核实的原生运动指令映射，不能按实际运动执行已完成计算。

3. 前向/返向独立速率（GNZB-08、XNZB-09）
卫星可分别设置 forwardDataRate 与 reverseDataRate，前向0.128～8 Mbps、返向0.064～2 Mbps。
按链路 direction 选择对应速率写入通信参数及 link_calc 信息速率；旧单一 dataRate 和设备默认速率兼容。
非法速率阻止保存。真实 GXB、BER 和时延随速率变化的求解仍依赖插件。

4. 射频干扰参数（GNZB-15、XNZB-05/10）
功率输入使用 -10～30 dBm、5 dB 步进；内部仍保存 W，换算为 10^((dBm-30)/10)。
保留未修改的历史大功率 W 值，不静默截断。新输入超界、清空或不符合档位不能确认。
新增俯仰角 -10～60° 的输入、保存、校验与清单字段。
俯仰角清单明确 elevationEngineMapped=false，尚未驱动原生干扰天线。

5. 连续帧状态和质量选路（GNZB-13/19/20、XNZB-13）
新增 RuntimeLinkDecisionTracker，接入已校验、已绑定当前运行的质量 Store。
默认3帧确认状态，缺测返回未知；硬失效门限需用户按设备标定值明确配置，未配置不推定中断门限。
候选须满足当前帧 GXB≥6 dB、BER≤1E-5，以及启停、方向、端点和可配置空域隔离约束。
按相同端点和方向分组选路。组织运用优先级先约束体制，同体制内前向按接收干扰功率升序、GXB降序；返向按BER升序、GXB降序，最终按链路编号确定顺序。
态势表、质量详情和地图接入同一帧判定；确认的劣化/中断显示红色，错误或换运行清除旧判定。
候选排序、排除原因、GXB/BER、帧号和时刻可在有有效输入后的“选路判定”页签查看。

6. 防抖与决策记录（GNZB-21/22、XNZB-14/15）
质量选路同时检查连续相同候选、质量改善及冷却窗口。默认BER至少改善10倍或GXB增加3 dB；冷却默认5秒及10帧，两者均需满足。
默认稳定次数由1改为3，保留旧场景显式值。规则脚本检查周期从固定3秒改为场景timeStep。
本机质量选路始终复核候选一致性；历史一致性开关仅作用于规则脚本，界面明确区分。
保存最多200条本机决策变更，含前后链路、方向、原因、帧号、仿真时刻和指标。
所有本机质量决策标注 LOCAL_DECISION，不写成实际引擎切换成功，不并入真实切换成功率或标准切换CSV。
